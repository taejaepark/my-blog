# Build 서브에이전트 지침 — 픽셀 아트 에디터

## 배경
이 프로젝트는 마크다운 블로그 + 미니 웹앱 포트폴리오(`/apps/{앱이름}/`)다. 픽셀 아트 에디터에 대한 구현 계획이 이미 `/apps/pixel-art-editor/spec.md`에 사용자 승인을 받아 확정되어 있다.

## 이 작업에서 할 일
`/apps/pixel-art-editor/spec.md`를 읽고, 그 계획을 그대로 구현한다.

만들 파일 (모두 `/apps/pixel-art-editor/` 안에):
- `index.html`
- `style.css`
- `script.js`

## 범위 제한 (중요)
- **`/apps/pixel-art-editor/` 폴더 밖의 어떤 파일도 수정하지 마라.** 블로그 본체(`index.html`, `assets/`, `templates/`, `build.js`, `posts/` 등)와 다른 앱(`/apps/2048/`)은 절대 건드리지 않는다.
- `/apps/pixel-art-editor/plan-instructions.md`, `spec.md`, `build-instructions.md`는 그대로 둔다 (삭제/수정 금지).
- spec.md에 없는 기능을 추가하지 않는다 (과설계 금지). spec.md에 명시된 범위만 정확히 구현한다 — 레이어, 실행취소/다시실행, 애니메이션, 이미지 불러오기 등은 만들지 않는다.

## 프로젝트 전역 제약 (CLAUDE.md)
- 프레임워크/번들러 금지. 순수 HTML/CSS/JS.
- 외부 라이브러리 사용 최소화. spec.md에 따라 외부 라이브러리 없이 구현한다.
- 모바일에서 사용 가능해야 한다 (spec.md의 터치/반응형 설계를 그대로 구현).
- 주석은 WHY가 비자명한 경우에만 최소한으로 작성한다.

## 완료 조건
- `index.html`을 열었을 때 16x16 캔버스 격자, 색상 팔레트(기본 스와치 + 커스텀 색상 입력 + 지우개), 전체 지우기 버튼, PNG 저장 버튼, 다크모드 토글 버튼이 모두 존재해야 한다.
- 클릭/드래그로 도트가 칠해지고, PNG 저장 버튼이 16x16 원본 해상도의 유효한 PNG를 다운로드해야 한다 (spec.md 6번 항목대로).

## 유의사항
- 이 단계에서는 브라우저 실행 검증(스크린샷 등)까지 할 필요는 없다 — 그건 별도의 Review 서브에이전트가 담당한다. 다만 코드 자체에 문법 오류가 없는지, 로직이 spec.md와 일치하는지는 스스로 점검하고 끝내라.
- 작업이 끝나면 만든 파일 목록과 각 파일의 핵심 구현 포인트를 간단히 보고해라.
