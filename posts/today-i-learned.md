Claude Code로 이 블로그를 만들면서, 화면에 보이는 걸 만들 때 HTML·CSS·JavaScript가 각각 어떤 역할을 하는지 다시 정리해봤다.

## HTML — 구조와 내용

페이지에 무엇이 있는지를 나타낸다. 제목, 문단, 목록, 링크처럼 콘텐츠의 뼈대를 잡는 역할.

- `<header>`, `<main>`, `<footer>` 같은 태그로 페이지의 큰 영역을 나눈다.
- `<h1>`, `<p>`, `<ul>`, `<a>` 등으로 실제 글 내용을 표현한다.
- 이 블로그에서는 마크다운 파일이 빌드 스크립트를 거쳐 이 HTML로 변환된다.

## CSS — 디자인과 레이아웃

HTML로 만든 구조에 색, 여백, 글꼴, 배치를 입힌다.

- CSS 커스텀 프로퍼티(`--bg`, `--text` 같은 변수)로 라이트/다크 테마의 색상 값을 한곳에서 관리했다.
- `max-width`와 `margin: 0 auto`로 본문 폭을 제한해 읽기 편하게 만들었다.
- `@media` 쿼리로 화면이 좁을 때(모바일) 여백과 글자 크기를 다르게 적용했다.

## JavaScript — 동작과 상호작용

정적인 페이지에 동적인 기능을 더한다.

- 다크모드 토글 버튼을 클릭하면 `data-theme` 속성을 바꿔 테마를 전환한다.
- 선택한 테마를 `localStorage`에 저장해 다음 방문 때도 유지되게 했다.
- 페이지가 그려지기 전에 저장된 테마를 먼저 적용하는 인라인 스크립트를 넣어서, 새로고침할 때 테마가 잠깐 잘못 보였다가 바뀌는 현상(FOUC)을 막았다.

세 가지 언어가 각각 구조, 디자인, 동작을 나눠 맡는다는 걸 직접 만들어보며 몸으로 이해할 수 있었다.
